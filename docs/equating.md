# Score equating (flexpyequate)

English | [日本語](equating.ja.md)

**flexpyequate** is a separate package from the same repository for equating **score
distributions**: mean, linear and equipercentile equating, the methods for an anchor test,
log-linear presmoothing and kernel equating. It depends on NumPy, SciPy and pandas only, and is
not installed with flexpyirt: install it with `pip install flexpyequate`. It has the same version
number as flexpyirt.

Equating that needs item parameters (IRT true-score and observed-score equating, scale linking
with `link()`) is part of flexpyirt: see the [user guide](guide.md).

On the documentation site, the rest of this page is the package's
[README](../packages/flexpyequate/README.md): features, installation, examples and notes on
agreement with R.
